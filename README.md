# eshop - онлайн-магазин мебели и предметов интерьера
Проект на Django 5.2, реализована адаптивная верстка на основе Bootstrap 5. 

## Технологии 
Django - бэкенд 
JavaScript + Ajax - фронтенд (для обновления отдельных блоков html-кода) 
PostgreSQL - база данных 

## Возможности
- авторизация и регистрация пользователей
- добавление товаров в корзину
- оформление заказов
- выбор способа сортировки товаров на странице
- поиск товаров через форму поиска
- возможность фильтрации товаров
- стилизация встроенной админ-панели под цветовую гамму сайта

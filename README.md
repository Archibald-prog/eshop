# 🛋️ Eshop — Магазин мебели и предметов интерьера

Полнофункциональный интернет-магазин на **Django 5.2**. Реализована бесшовная работа корзины, динамические фильтры и профессиональная серверная настройка.

## 🛠 Статус проекта: Полностью развернут и доступен для тестирования. 

🔗 **Живое демо:** [http://79.174.77.122/eshop/](http://79.174.77.122/eshop/)

---

## 🛠 Технологический стек
*   **Backend:** Django 5.2, Python 3.x, PostgreSQL.
*   **Frontend:** JavaScript (jQuery), AJAX, Bootstrap 5 (Responsive Design).
*   **Infrastructure:** Nginx, Gunicorn, Systemd, Python-dotenv.

---

## 🚀 Ключевые технические особенности
*   **AJAX-корзина:** Полная реализация добавления, удаления и изменения количества товаров без перезагрузки страницы. Использовано делегирование событий и универсальные обработчики для мобильной оптимизации.
*   **Сложная фильтрация:** Система поиска и фильтров с сохранением состояния при пагинации (манипуляции с `QueryDict`).
*   **Бизнес-логика в моделях:** Расчет стоимости и условий доставки инкапсулирован в методы моделей и Custom QuerySets (Fat Models).
*   **Маски и валидация:** Клиентская валидация форм и маски ввода (телефон) на чистом JS.

---

## ⚙️ Deployment & Infrastructure (DevOps)
Проект развернут на **VPS (Ubuntu)** с архитектурой, готовой к продакшену:
*   **Reverse Proxy (Nginx):** Настроена маршрутизация через префикс `/eshop/` с передачей заголовка `SCRIPT_NAME`, что позволяет запускать несколько Django-проектов на одном IP.
*   **Gunicorn + Sockets:** Использование UNIX-сокетов для высокопроизводительной связи между веб-сервером и приложением.
*   **Security:** Конфигурация через `.env`, настройка `CSRF_TRUSTED_ORIGINS` для работы за прокси-сервером.
*   **Workflow:** Автоматизированный деплой через Git (Reset/Pull/Collectstatic/Restart).

## 💻 Как запустить локально
1. Клонировать репозиторий: `git clone https://github.com/Archibald-prog/eshop.git` 
2. Создать виртуальное окружение: `python -m venv venv`
3. Установить зависимости: `pip install -r requirements.txt`
4. Создать базу данных в своей локальной PostgreSQL (через клиент pgAdmin или терминал) 
5. Создать файл `.env` на основе `.env.example` (скопируйте шаблон настроек командой `cp .env.example .env`) 
6. В файле `.env` указать свои локальные значения переменных - включая параметры БД в переменной `DATABASE_URL`
7. Применить миграции: `python manage.py migrate`
8. Заполнить базу тестовыми данными: `python manage.py loaddata fixtures/init_db.json`
9. Запустить сервер: `python manage.py runserver`
